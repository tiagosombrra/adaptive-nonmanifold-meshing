# Scientific validation

This directory contains public validation descriptions and expected values for maintained software regressions.

The Computers & Graphics Figure 7 Eistute case is documented under `computers-and-graphics/figure-7-eistute/` and can be reproduced from the repository root with:

```bash
bash reproduce_eistute_linux.sh
```

Validation records in this repository apply to the public software implementation and should not be interpreted as editorial or manuscript assets.
